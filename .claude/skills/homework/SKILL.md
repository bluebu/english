# homework：群公告 → A4 每日打卡单

用户把家长群的作业公告贴过来，产出一张 A4 打印单：每项一张色条卡片 + 右侧大勾选框。
**脚本用相对路径，一律在 `homework/` 目录下运行。**

- `specs/<YYYYMMDD>.txt` — 作业内容（本 skill 负责写）
- `sheets/<YYYYMMDD>.html` / `.pdf` — 生成的打印单
- `generate_checklist.py` — 生成脚本；spec 完整语法见 `homework/README.md`

## 流程

1. **整理群公告 → spec**（见下面的整理规则），写到 `specs/<YYYYMMDD>.txt`，文件名和 `date:` 用公告里的日期（公告只写「8月20日」时年份按当年）。
2. 生成：`python3 generate_checklist.py specs/<YYYYMMDD>.txt --pdf`
3. **自检**：Read 生成的 PDF 看排版（别凭 HTML 源码想象）。目标是**干净地放满一页**：
   底部剩太多空白就加大 `memo:` 行数，快溢出到第二页就减少备注行 / 精简说明行。
4. `open sheets/<YYYYMMDD>.pdf` 给用户看，确认后 commit（用户要求才 push）。

## 整理规则

- **不增不删**：公告里的任务一项不落、也不自己加任务。群公告序号常常重复或错乱（同时出现两个 5⃣️），
  **按内容重排成连续序号**，并在汇报时说明这点。
- 一件事一张卡：公告里「①听：音频 120 分钟 + 指读 2 遍」这种一项含两小任务的，拆成两张卡，各自能打勾。
- 标题短、细节下沉：主任务写标题（`超8 Lesson 2`），页码/范围等细节放缩进的 `*` 列表或说明行。
- 数量、时长、遍数放 `|` 后面当小标签（`| 120 分钟`、`| 抄 4 个 · 每个 2 遍`）。
- **给孩子留可填的地方**（这是纸质单的价值）：时长任务写 `今天实际听了 __ 分钟`；
  「读 N 遍」写 `每读完一遍勾一个小格 <<N>>`；「抄 N 个单词」留 N 条填空 `________`。
- 列出具体单词的作业用 `+ word = 释义`（自动两列、每词一个小勾选框，孩子按天勾掉）；释义照抄公告。
- 类别标签按语义选（听/指→蓝，读/点→橙，词/写→绿，练/AI→紫，语/法→红），让同类作业颜色成组；
  标签不印在纸上，只决定色条。
- 排版细节：页码范围等区间用 en dash（`27–28`），中文与英文/数字之间留空格。
- 公告末尾的「打卡模板」「多听音频」这类叮嘱**不进卡片**（页脚已有一句提示 + 鼓励语）；
  真要改提示文案用 `tip-left:` / `tip-right:` / `cheer:`。

## 注意

- 只是重复昨天的作业换个日期时，`cp specs/<旧>.txt specs/<新>.txt` 再改 `date:` 和变动项，别从头写。
- 公告有歧义（页码写成 `3537`、单词数与列表数量不符）先问用户，别猜。
