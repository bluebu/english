# 每日打卡作业单（A4 打印）

群公告里的作业整理成一张 A4 清单：每项前面一个勾选框，做完打勾。

```
homework/
  generate_checklist.py     生成脚本
  specs/<日期>.txt          作业内容（手写，一天一份）
  sheets/<日期>.html|.pdf   生成的打印单
```

## 生成

在 `homework/` 目录下运行：

```bash
python3 generate_checklist.py specs/20260820.txt --pdf   # HTML + PDF
python3 generate_checklist.py specs/20260820.txt         # 只出 HTML（先在浏览器看排版）
python3 generate_checklist.py --pdf                      # 不给 spec 就用 specs/ 里最新改动的那份
```

PDF 由无头 Chrome 导出，直接打印即可（A4 竖版，通常一页；任务多了会自动续页，卡片不会被切断）。

生成后脚本会**自动刷新 `index.html` 的打卡单列表**（`LIST:BEGIN` / `LIST:END` 之间那段由脚本生成，别手改）：
按日期倒序，日期和项数从对应 spec 读，PDF 存在才给 PDF 链接。

## spec 写法

```
# 井号开头是注释
date: 8月20日                    # 页头日期胶囊，不写就不显示
title: 每日打卡作业              # 默认「每日打卡作业」
subtitle: Daily Checklist        # 标题下的小字英文
cheer: 加油，每天一小步 👣 成就未来一大步
memo: 2                          # 底部备注区行数，0 = 不要备注区
tip-left: 做完一项，就在右边的方框里打一个 ✓
tip-right: 全部完成后，按模板在群里打卡

[听] 听外教音频 | 120 分钟          ← 任务行：[类别] 标题 | 右侧小标签
    今天实际听了 __ 分钟            ← 缩进 = 这项任务的说明行
[点读] 点读 · 超8 Lesson 2
    * 第 27–28 页 单词部分          ← * 开头 = 圆点列表项
    * 第 35–36 页 划线部分
[练] 单词抄写 | 每天 2 个
    + clean = 清洁的，干净的        ← + 开头 = 单词表条目（自动两列，每词一个小勾选框）
    + clock = 钟；计时
```

说明行里的两个记号：

- `__` 连续下划线 → 填空横线，下划线越多线越长（`________` 约 88px）
- `<<3>>` → 3 个小方格（例如「读 3 遍，读完一遍勾一个」）

`|` 前面是标题，后面是标题右边那个小标签；不写 `|` 就没有标签。

## 类别与颜色

`[类别]` 只决定左侧色条颜色，不会印在纸上。按关键字取色：

| 关键字 | 颜色 |
| --- | --- |
| 听 / 指 | 蓝 |
| 读 / 点 | 橙 |
| 词 / 写 | 绿 |
| 练 / AI | 紫 |
| 语 / 法 | 红 |

也可以直接写色号 `[#2f855a]`；整个 `[...]` 省掉就按五色循环。
